> 重要前置提醒：龙虎榜是**收盘后披露的滞后数据**，只展示买卖前五席位，**不是全部资金**，不能直接当成买入信号，仅作为资金面线索，不构成投资建议。

## 一、先搞懂：什么情况才会上龙虎榜（交易所规则）证券时报

满足下面任意一条，才会上榜：

1. 日涨跌幅偏离值 ±7%（个股涨跌幅 - 对应指数涨跌幅）
2. 日振幅 ≥15%
3. 日换手率 ≥20%
4. 连续 3 日涨跌幅偏离累计 ±20%（ST 股 ±12%）
5. 连续 3 日换手率异常放大

> 
> 沪市：每个条件取前 3 名；深市：每个条件取前 5 名。
> 上榜类型会标注：【当日异动】、【三日异动】，**三日榜是合并 3 天买卖总额，和单日榜不能混在一起看**，这是新手最容易踩的坑。

龙虎榜每条记录包含：股票名称、上榜原因、买 1~ 买 5、卖 1~ 卖 5，每一席位：买入金额、卖出金额、净额（买入 - 卖出）。

## 二、第一步：识别席位类型（最核心）

席位分三大类：

1. **机构专用**：基金、保险、券商资管、QFII 等。
   - 特点：偏基本面、趋势，一般不会隔日无脑砸；机构连续净买入，代表基本面 / 赛道逻辑被认可；机构大额净卖出，往往是基本面调仓、利空兑现，警示价值很高证券时报。
   - 注意：有游资租借机构通道伪装 “假机构”，不能只看名字。
2. **营业部席位（游资）**：各大券商营业部，就是短线游资。
   - 不同营业部风格固定：有的主打连板接力、有的一日游套利、有的擅长低吸、有的喜欢砸盘。
   - 你做资金系统的时候，要维护一个**席位标签库**：标记【接力型】【一日游】【砸盘王】【趋势游资】。
3. **沪股通 / 深股通（北向）**：外资，偏波段、价值，不是纯短线。

✅ 经典组合解读：

- 机构 + 知名游资一起买入：**题材热度 + 基本面逻辑共振，持续性最好**
- 全是机构买入：偏趋势，波动相对温和，连板爆发力弱
- 全是一日游游资：次日高开兑现概率大，容易一日游
- 买榜游资、卖榜机构：机构在兑现，游资来接盘，风险很高
- 买榜机构、卖榜一堆游资：机构接筹码，游资获利离场，偏良性换手

## 三、第二步：看资金结构（定量指标，适合你做系统）

### 1）龙虎榜净买入额 = 买 5 合计 − 卖 5 合计

> 
> 净买入为正，不代表明天一定涨；净卖出为负，抛压偏大。
> 重点：**龙虎榜只统计前五席位，占总成交可能只有很小一部分，剩下的大量散户 / 其他资金看不到**。

### 2）龙虎资金占比（非常关键，你的系统一定要算这个字段）

\(龙虎成交占比 = \frac{买5总买入+卖5总卖出}{当日个股总成交额}\)

- 占比越高：筹码集中在这几个大资金手里，博弈强度大；>30% 属于高集中度，容易大起大落
- 占比很低：龙虎榜参考意义弱，主力资金不在前五席位里

### 3）买一集中度

买一买入金额 ÷ 买 5 总买入

- 买一独大（比如买一占 70% 以上）：孤庄，第二天容易砸盘，没人接力，风险高
- 买 1~ 买 5 金额比较均匀：多家资金合力，接力氛围更好

### 4）买卖对照

- 一边倒：买盘远大于卖盘，资金抢筹；卖盘远大于买盘，集中出逃
- 对倒：**同一个席位同时出现在买榜 + 卖榜**，典型做量、吸引跟风，很多是诱多出货，重点标记！

## 四、第三步：结合位置、题材、情绪，不能单看榜单

同样的龙虎数据，高位和低位完全两个意思：

1. **低位首板上榜**：游资试盘、机构初建仓，重点看题材是不是主线；
2. **中位连板换手上榜**：看是换庄接力，还是老资金出货；
3. **高位、已经大涨后的上榜**：哪怕是知名游资买入，极大可能是诱多、隔日兑现，风险最大。

还要看：

- 板块：是不是当下市场主线？板块有没有批量涨停？孤立个股的龙虎榜持续性差；
- 大盘情绪：退潮期，再好的龙虎榜也容易埋人；情绪回暖期溢价更高；
- 分时：涨停是硬板封死，还是炸板反复烂板上榜？烂板上榜分歧大。

## 五、第四步：时序跟踪（适合你的 A 股资金系统，做连续追踪）

单日龙虎是单点，**连续多日龙虎才是高价值信号**：

1. 连续多日机构净买入：机构持续加仓，趋势信号；
2. 第一天游资买，第二天同一个游资卖出：标准一日游；
3. 席位锁仓：上榜之后第二天该席位没有卖出，代表资金愿意持有；
4. 轮换接力：第一天 A 游资，第二天 B 游资接，老资金离场，良性换手。

> 
> 你的系统可以做：**席位持仓时序表**，跟踪同一个席位在个股上的连续买卖。

## 六、高频陷阱（写进你的系统告警规则）

1. **滞后性**：晚上才出数据，资金当天已经买完了，散户第二天才看到，天然后手；
2. **马甲 / 分仓**：游资分仓到几十个营业部，龙虎只显示前五，真实仓位看不见；也可以借别人席位伪装；
3. **三日榜坑**：三日净买入看着很大，其实是第一天买、第三天悄悄卖，总额是合并统计，容易被误导；
4. **对倒做榜**：自买自卖，制造热闹假象，吸引跟风；
5. **知名游资光环**：很多游资上榜就是为了吸引跟风，第二天高开直接砸给散户；
6. 机构也会错：机构买入≠一定上涨，机构也会止损、调仓。

## 七、给你一套标准化复盘流程（可直接写成系统的打分逻辑）

1. 先看【上榜类型】：单日 / 三日异动，区分开；
2. 计算：龙虎成交占比、买一集中度、龙虎净额；
3. 打标签：席位构成（机构 / 北向 / 游资组合）、游资历史风格；
4. 定位个股位置：低位 / 中位 / 高位，题材归属；
5. 查历史时序：该席位之前在这只票的操作；
6. 告警识别：同席位对倒、高位独大买一、一日游席位扎堆；
7. 最后结合板块情绪、大盘环境综合打分。

# 一、席位构成标签（一级标签，直接给榜单打组合标签，适合你系统）

> 
> 枚举，可多选，一条龙虎记录可以是多个标签组合

1. **机构专用**：交易所 “机构专用” 单元（公募、保险、资管、QFII）；⚠️ 有假机构通道，系统后续用历史回测校正
2. **北向（陆股通）**：沪股通专用、深股通专用；细分二级：**北向配置盘 / 北向交易盘**
3. **游资**：券商营业部（绝大多数龙虎席位）
4. **散户大本营（拉萨天团）**：东财拉萨系列，独立标签，不属于普通游资
5. **外资券商席位**：瑞银花园石桥路、高盛世纪大道、摩根大通银城中路（很多是外资机构，和北向不是一回事）
6. **量化席位**：高频量化打板营业部（华鑫、国盛部分席位）
7. **混合组合标签（给整单龙虎榜打标签，你最需要的）**
   - 纯机构：买榜以机构为主
   - 机构 + 北向
   - 机构 + 游资（合力票，质量最高）
   - 纯游资
   - 游资 + 北向
   - 拉萨扎堆（多个拉萨席位同时上榜）
   - 机构出逃、游资接盘（卖榜机构，买榜游资，风险标签）
   - 游资出逃、机构接盘（良性换手标签）

# 二、游资历史风格标签库（二级标签，给单个营业部绑定，存入席位字典）

## 基础风格枚举（固定标签，你的数据库用这个）

- **龙头接力**：主打主线高标、分歧板，敢于高位接龙头，持仓 2–3 天，不会隔日无脑砸
- **首板挖掘**：专门做低位首板、事件潜伏，1 板为主，很少去高位连板
- **低吸派**：不主动打板，喜欢分歧阴线、回调低吸，博弈回流
- **排板一字（通道流）**：一字板排队，拿到溢价隔日兑现（养家风格）
- **一日游 / 隔日砸**：买入次日优先卖出，几乎不格局，风险标签
- **做 T 波段**：同一只票反复来回买卖，持续几天滚动，锁仓 + 做 T
- **点火先锋**：主动拉板、引导合力，不一定锁仓，负责带动板块情绪
- **独庄孤买**：经常买一独大，单一资金重仓，接力差，容易崩盘
- **量化高频**：程序化打板，快进快出，无主观长线逻辑
- **潜伏埋伏**：提前埋伏事件、消息，等兑现离场
- **砸盘兑现**：高位擅长出货，上榜买入后次日砸盘概率高

> 
> 系统设计：每个席位绑定 1 个主风格 + 多个副标签，同时维护**历史胜率、隔日兑现率、锁仓率、对倒率**四个量化指标，自动动态修正标签，不要写死（游资会换风格、换马甲）

> 
> 提示：席位会换、分仓、马甲，**只作为初始标签，系统必须用历史交易数据自动校验**，不能静态硬编码

8. **宁波桑田路｜国盛证券宁波桑田路**

# 四、自动更新规则（重点，避免静态标签过时）

1. 统计该席位近 30 次上榜：买入后**次日卖出占比 > 70% → 自动打上【一日游】**
2. 连续 3 次买入后多日不卖 → 增加【锁仓 / 波段】标签
3. 经常同票同时出现在买和卖 → 【对倒偏好】
4. 经常只出现在首板，几乎不上 3 板以上 → 【首板挖掘】
5. 频繁高位 5 板以上买入 → 【龙头接力】

# 五、组合标签示例（你打分系统直接用）

- 榜单标签：机构 + 游资合力；席位标签：机构 (趋势)、赵老哥 (龙头接力)、作手新一 (换手接力) → 加分项
- 榜单标签：纯一日游游资；席位：佛山系、成都南北环 → 减分，隔日抛压预警
- 榜单标签：拉萨扎堆；席位：3 个拉萨 → 强风险告警
- 榜单标签：机构出逃游资接盘；卖榜机构、买榜陈小群 / 桑田路 → 风险标签

# 六、补充边界说明（避坑）

1. **机构专用是一个单元，不是某一家基金**，游资可以租借通道，所以不能 100% 信任 “机构” 标签，必须靠回测识别假机构
2. **北向（沪 / 深股通专用）≠瑞银 / 高盛外资营业部**，是两套独立通道，分开打标签
3. 同一个大佬会**新开营业部马甲**，静态名单一定会失效，自动化统计指标优先于人工标签
